# VS Automóveis — Landing Page

Landing page responsiva criada com base no mockup enviado.

## Estrutura
- `index.html` — estrutura completa
- `style.css` — visual, responsividade e animações
- `script.js` — menu mobile, navegação ativa, reveal animations e formulário para WhatsApp
- `assets/` — coloque aqui as imagens finais
